## Root causes, with evidence

**1. Recovery 18/20, a measured mechanism.** Both failing rows are PR 1.0 "held" pedestal-event
rows (pedestal −27 / −15 dBFS, event −6 dBFS):

| Row (pedestal) | `late_max` R11a | `late_max` R12 |
|---|---|---|
| −27 dBFS | 0.056 dB | 0.671 dB |
| −15 dBFS | 0.011 dB | 0.407 dB |

- The element normalises by its peak envelope. The Chebyshev terms are pure harmonics only when the
  envelope equals the signal's own peak (`v = sin θ`).
- After a loud event the envelope is held (0.3 s release, an unmeasured choice), and the quieter
  pedestal runs at `|v| < 1`. There the odd terms carry a linear part (`T3 ≈ −3v`, `T5 ≈ 5v`,
  `T7 ≈ −7v`) that changes the fundamental gain.
- Verified numerically with the PR 1.0 coefficients and the envelope held at 1:

| Signal amplitude (envelope held at 1) | Fundamental change |
|---|---|
| 1.0 | +0.000 dB |
| 0.707 | +0.19 dB |
| 0.35 | +0.54 dB |
| 0.112 | +0.71 dB |

- The analytic limit is `−3a₃ + 5a₅ − 7a₇` = 0.088, i.e. +0.73 dB.
- This is the size of the late recovery error. The two-tone (−1) and link C2 (−1) losses are
  probably the same leak on non-sinusoidal `v`, but that is **not verified**.

**2. Falsifier 2, the harmonic rows (1 kHz, PR .7, the C++ core).**

| Input | Harmonic | R12 | Reference |
|---|---|---|---|
| −24 dBFS | H2 / H3 / H4 / H5 | −53.8 / −60.5 / −72.9 / −70.8 dBc | −53.0 / −54.2 / −58.7 / −63.1 |
| −12 dBFS | H2 | −45.9 dBc | −50.2 |
| −4 dBFS | H2 | −45.8 dBc | −55.3 |

- The table holds each ratio constant above switch-on: the −22 to −10 dBFS average.
- The UAD's ratios fall with level there (measured H2 slope −0.27 dB/dB at PR .5, −0.48 at PR .8).
  So H2 overshoots by 4–10 dB at loud levels, and H3/H4 undershoot at −24 dBFS.
- A level-flat table is the wrong law, measured. The scope wall was one change, so this was not
  touched.

**3. Witness H3, −6.4 dB.**
- The witness is 1 kHz, −16 dBFS, PR .35. The table interpolates H3 linearly in PR between the .25
  node (−65.0 dBc) and the .5 node (−57.7), giving about −61.6 dBc. The UAD's witness H3 is
  −56.4 dBc.
- **Hypothesis, not tested:** the PR dependence between nodes is not linear, or there is a
  level/frequency difference from the 1.2 kHz −22..−10 dBFS table.

**What did improve:**
- The witness moved 8–36 dB closer: H2, H4 and H5 are within 6 dB, and H3 is 0.4 dB out.
- IMD +107 cells, sweep +167, music FIT slightly better.
- GR laws are unchanged within 0.002 dB (DEV), and settled is unchanged.

The mechanism is real; this law, normalised by a held peak envelope with level-flat ratios, is
not the right one.

**Phase:**
- H2 is 180° and H3 is 170–180°, both coherent within 1° and 28° respectively.

## Pre-registration

This section was written before any R12 build or render; the verdict above was added after.

**The change (one).** The reference's per-channel input element, gated by its own input level, is
added ahead of the cell as a measured static law (`core/MultiCompOptoInputElement.hpp`,
generated). Its strength is a continuous function of the channel's own input peak envelope:
- **gate:** logistic, mid −23.58 dBFS peak, slope 1.863 dB;
- **ratios:** above switch-on, the measured UAD − R11a residual H2..H7, by PR node and mode;
- **shape:** a Chebyshev shaper on the peak-normalised input;
- no linked term, no detector involvement, no branch on signal class.

The physical R11a is otherwise unchanged.

**Falsifier, viewed once on the frozen build through the real AU:**
1. 1 kHz witness H2–H5 within 6 dB of the UAD (`opto_au_harmonic_map.py witness`).
2. The MultiCompCore CTest harmonic-rows gate ("Opto H2-H5 and even-to-odd balance match all six
   measured points") passes. It is currently the known 19/20 failure.

**No-regression tolerances.** Every number is reported next to the R11a value, measured on the
current reference build `f7723433` (sample-identical to `4aea742e`). No threshold moves.

| Settled (122, 0.5 dB) | 120, worst 0.653 dB | no R11a-passing cell may fail; worst \|e\| may rise ≤ 0.02 dB |

**Rules:**
- If the witness passes but music or link regress beyond tolerance: report and stop. No second

  not tuned.
