# Sunset Circuits screenshots

Sunset Circuits re-skins its whole panel per mode: the accent color, the mode
sub-panel, and a handful of mode-specific controls all change. One shot per mode
is therefore the useful set, rather than a single "main UI" capture.

All shots are the standalone build at the default window size, on the factory
preset "Neon Nights".

| Filename | What it shows |
| --- | --- |
| `01-main-ui.png` | Full UI in Cosmos, the default mode. Amber panel, the six mode rockers along the top, oscillator and mixer column on the left, filter and the two envelopes in the center, LFOs and mod matrix on the right, sequencer and effects along the bottom over the keyboard. The BBD CHORUS sub-panel is set to I+II. |
| `02-mode-oracle.png` | Oracle. Two-oscillator layout with no sub, the AUX OSC slot reading "no auxiliary oscillator", and the POLY-MOD / SYNC sub-panel with its Filter Env and Osc 2 routing knobs. |
| `03-mode-mono.png` | Mono. Grey panel, two oscillators plus the sub, and the RING / SYNC sub-panel with the Ring knob and the Hard Sync button. |
| `04-mode-modular.png` | Modular. Green panel with the third oscillator, the AUDIO PATCH / FILTER sub-panel carrying S&H, Osc2 to Osc1, Osc3 to VCF and Ring, and the reverb section showing its fixed spring send. |
| `05-mode-prism.png` | Prism. The left column becomes the four-operator matrix, each operator with ratio, fine, level, velocity, key scaling and its own envelope; operator 4 carries feedback. The ALGORITHM sub-panel lists the eight routings with a diagram of the active one. |
| `06-mode-acid.png` | Acid. Orange panel, single-oscillator engine with Osc 2 bypassed, the ACID ENGINE signal-path diagram, accent and slide controls, and the pattern sequencer with its Gate, Pitch, Acc and Slide lanes. |
| `07-preset-browser.png` | The preset browser, factory presets grouped in a column per mode with the user library in its own column. |
