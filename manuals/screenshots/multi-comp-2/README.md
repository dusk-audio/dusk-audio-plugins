# Multi-Comp 2 screenshots

Multi-Comp 2 shows a different face for each of its eight modes, so there is one shot per mode plus the SETTINGS drawer. All shots are the 1120 x 380 window captured at 2x and scaled to 1600 px wide, with every control at its default (the preset field reads Default on OPTO and Custom on the other modes, because the mode itself differs from the default).

| Filename | What it shows |
| --- | --- |
| `01-mode-opto.png` | OPTO face: header with the preset list, the mode row (eight tabs, AUTO MAKEUP, BYPASS, SETTINGS), GAIN, PEAK REDUCTION, the LIMIT / COMPRESS toggle, the VU with its GR / +10 / +4 switch, and the SC HP and MIX set screws. Used in the Overview. |
| `02-mode-fet-black.png` | FET BLACK face: INPUT, OUTPUT, ATTACK, RELEASE, the 20 / 12 / 8 / 4 / ALL ratio buttons, the VU, the GR / +8 / +4 / OFF meter buttons and MIX. |
| `03-mode-vca.png` | VCA face: THRESHOLD with the BELOW / ABOVE lamps and PULL/SC, COMPRESSION, OUTPUT GAIN, the INPUT / OUTPUT / GR meter keys, the meter and MIX. |
| `04-mode-bus.png` | BUS face: the dB COMPRESSION meter and IN switch, THRESHOLD, RATIO, MAKE-UP, SC FILTER, MIX, ATTACK, RELEASE, HR, RATE and AUTO FADE. |
| `05-mode-fet-blue.png` | FET BLUE face: INPUT, HR, MIX, OUTPUT, ATTACK with its SLO stop, RELEASE, the 20 / 8 / 4 / 2 / SC buttons, the VU and the meter buttons. |
| `06-mode-studio-vca.png` | STUDIO VCA face: INPUT, RATIO, ATTACK, AUTO RELEASE, THRESHOLD, RELEASE, the I/O meter with its INPUT / OUTPUT switch, the GAIN REDUCTION meter, MAKE UP GAIN and DRY/WET. |
| `07-mode-digital.png` | DIGITAL face: INPUT and OUTPUT meters, the gain reduction VU, the SC HP slider, THRESHOLD, RATIO, KNEE, ATTACK, RELEASE, LOOKAHEAD, MIX, OUTPUT and ADAPTIVE RELEASE. |
| `08-mode-multiband.png` | MULTIBAND face: the band enable strip, band tabs with B and S, the four band meters with the crossover handles, and the selected band's knobs with OUTPUT and MIX. |
| `09-settings-drawer.png` | The SETTINGS drawer open over FET BLACK: SIDECHAIN, PROCESSING, STEREO, DRIVE, LOOKAHEAD (greyed outside DIGITAL and MULTIBAND) and FET BLACK groups. |
